# Arin E Catalino — Portfolio

A responsive four-page portfolio created with Next.js and JSX for Exercises 1 and 2.

## Pages

- Home — `/`
- Portfolio — `/portfolio`
- About — `/about`
- Gallery — `/gallery`

The shared header uses the current route to highlight the active navigation button. It also includes a responsive menu for smaller screens.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.
